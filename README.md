# 📖 Từ điển tiếng Trung thuộc Linh (Spiritual Chinese Dictionary)

Từ điển thuộc linh đa ngôn ngữ (Trung - Việt - Anh), được thiết kế đặc biệt cho việc tra cứu và học tập sâu sắc. Ứng dụng tự động phát hiện ngôn ngữ đầu vào và cung cấp các câu Kinh Thánh minh họa.

## ✨ Tính năng chính

- 🔍 **Tìm kiếm thông minh**: Tự động nhận diện Tiếng Việt, Tiếng Trung (Giản/Phồn) hoặc Tiếng Anh.
- 📖 **Kinh Thánh đa ngữ**: Mỗi từ vựng kèm theo ví dụ Kinh Thánh ở 3 ngôn ngữ để đối chiếu.
- 🔊 **Hỗ trợ Pinyin**: Hiển thị phiên âm Pinyin (thủ công hoặc tự động) cho Hán tự.
- 📱 **Giao diện cao cấp**: Thiết kế mobile-first, mượt mà và mang phong cách trang trọng.
- ⚡ **Dữ liệu thời gian thực**: Sử dụng Google Sheets làm cơ sở dữ liệu, dễ dàng cập nhật và cộng tác.

## 🛠️ Công nghệ sử dụng

- **React 18** + **Vite**
- **TypeScript**
- **Tailwind CSS v4**
- **PapaParse** (Xử lý CSV)
- **Lucide React** (Biểu tượng)

## 🚀 Cài đặt và Chạy thử

1.  **Sao chép mã nguồn**: `git clone ...`
2.  **Cài đặt thư viện**: `npm install`
3.  **Cấu hình**: Tạo tệp `.env` với biến `VITE_GOOGLE_SHEET_URL`.
4.  **Chạy ứng dụng**: `npm run dev`
